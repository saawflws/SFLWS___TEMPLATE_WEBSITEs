# creative_agency — templates

Landing pages for creative, branding and design studios / digital agencies — bold, typographic,
positioning-led splashes. (Distinct from `it_consultancy`, which is for IT / software / systems
consultancies; this category is for brand and creative studios.)

Read the template's `META.md` before opening its source.

| Template | Path | Tags | Summary |
| --- | --- | --- | --- |
| **VANGUARD** | `vanguard/` | `fullscreen-video-hero` `monochrome-black-white` `podium-sharp-display` `agency-stat-row` | A single-screen React (Vite + Tailwind v4) brand-studio hero: muted video background, an oversized PODIUM Sharp headline ("Design. Disrupt. Conquer."), a positioning line, a "See Our Work" CTA and credibility stats. |

## Notes

Only one template here so far, and it is a **React project** (build step required), not a static
file. It is a single hero splash — the nav links (Projects / Studio / Offerings / Inquire) point
at sections not yet built, so treat it as a shell to extend.
