# streaming_service — templates

Landing / featured-content heroes for movie & TV streaming services (OTT / VOD) — full-bleed
video backgrounds with showcase carousels, in the Netflix/Prime mould.

Read the template's `META.md` before opening its source.

| Template | Path | Tags | Summary |
| --- | --- | --- | --- |
| **CINEMATIC** | `cinematic/` | `fullscreen-video-hero` `liquid-glass-ui` `imdb-title-carousel` `modal-heavy` | A single-viewport React (Vite + Tailwind v4) streaming hero: muted video background, a rotating IMDB-rated title carousel, and search / profile / trailer / detail modals. Monochrome black-and-glass, Inter type. |

## Notes

Only one template here so far, and it is a **React project** (build step required), not a static
file. It is a single non-scrolling hero with modal overlays — a featured-content splash, not a
full catalog or app. Its `index.html` title ("…Work Smarter.") is placeholder drift; the build
is a movie/TV streaming showcase.
