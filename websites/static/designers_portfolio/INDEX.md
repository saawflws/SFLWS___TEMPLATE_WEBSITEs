# designers_portfolio — templates

Print-monograph portfolios for brand and graphic designers. Both treat projects as printed
"spreads"; they are opposite ends of the same idea in tone, scale and dependencies.

Read the template's `META.md` before opening its `index.html`.

| Template | Path | Tags | Summary |
| --- | --- | --- | --- |
| **JUNO HARADA** | `junoharada/` | `risograph-print` `warm-cream-paper` `kinetic-typography` `cursor-dot-trail` | The bright riso one. Cream paper with red/blue/yellow riso inks, first-person-singular voice, draggable type specimens. Dependency-free vanilla JS, ~1,000 lines. |
| **SEVERIN HALBE** | `severinhalbe/` | `deep-green-and-gold` `somber-luxury` `gsap-scroll-choreography` `long-form-case-studies` | The somber studio one. Deep jungle green and gold, first-person-plural studio voice, a full manifesto essay and award-decorated case studies. GSAP/Lenis, ~2,750 lines. |

## Choosing between them

| If the designer... | Use |
| --- | --- |
| Is a solo practitioner with a playful, personal voice | `junoharada` |
| Is an established studio with awards and long-form case studies | `severinhalbe` |
| Needs the page to work with no external JS | `junoharada` |
| Wants heavy scroll choreography | `severinhalbe` |
