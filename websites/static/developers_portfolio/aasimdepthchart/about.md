Design concept: a "depth chart" — the whole page reads as a descent from surface-level product work down to systems internals. Dark navy base (
#0A0E16), brass/gold accent up top fading toward teal as you go deeper, Bricolage Grotesque for display type + Manrope body + IBM Plex Mono for data. Ties the tagline, the Skills section (literal depth bands with fake sonar readings), and project names (Strata, Compass, Ledger) into one idea instead of six unrelated sections.

What's built in:

Three.js particle field drifting behind the whole page, camera creeps forward on scroll
GSAP/ScrollTrigger: hero entrance sequence, parallax on the depth bands, timeline progress line, stat count-up
Motion for magnetic button hover + project card tilt
Reduced-motion respected throughout (skips the canvas and JS animations, shows final state instantly)
