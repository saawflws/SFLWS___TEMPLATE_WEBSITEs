# programmerblog — templates

Reading-first blogs for developers. Monospace-heavy, high information density, code as a
first-class content type.

Read the template's `META.md` before opening its `index.html`.

| Template | Path | Tags | Summary |
| --- | --- | --- | --- |
| **/dev/log** | `devlog/` | `terminal-hacker` `monospace-heavy` `three-state-theme-toggle` `code-snippet-showcase` | Terminal-flavored personal blog with a typewriter hero, copy-to-clipboard code blocks, a reading-progress bar, and a 3-state theme toggle (dark / light / cyber). |

## Notes

Only one template here so far. `devlog` ships three complete palettes rather than one — if a
brief calls for a light-mode developer blog, that is a toggle state, not a different template.
It also fetches live GitHub stars/forks on load; see its `META.md` before using it offline.
